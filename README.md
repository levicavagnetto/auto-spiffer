# Auto Spiffer

Version 1.0.0 is a ground-up rewrite as an Electron desktop app. It is being planned with
[OpenSpec](https://github.com/Fission-AI/OpenSpec): specs live in `openspec/specs/`, and work in progress in
`openspec/changes/`.

The previous Python app (v0.4.0) is on the `legacy` branch and its `v0.x` tags.
